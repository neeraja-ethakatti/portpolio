Neeraja Jagili Portfolio Website

Files included:
- index.html
- styles.css
- script.js
- assets/profile.jpg

How to use:
1. Extract the ZIP file.
2. Open index.html in your browser.
3. Edit text in index.html to update profile details.
4. Replace assets/profile.jpg if you want to use another profile image.
5. Upload all files to Netlify, Vercel, GitHub Pages, or any hosting provider.
